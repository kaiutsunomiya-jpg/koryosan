# 校了さん PWA v4 — GitHub Pages公開用

「校了さん」の5画面（タスク／曲リスト／練習タイテ／セトリ作成／メトロノーム）を改良したバージョンです。既存の公開先 `koryosan` を更新するだけで利用できます。アプリアイコン、初期8曲、メトロノーム、既存のタスク・メモ・3スロットのデータ構造を引き継ぎます。

## 今回の仕様変更

### 共通デザイン

- 操作方法などの冗長な説明文、空一覧の案内を削除。必要な操作は主にアイコンと短いラベルで表示します。
- スマホ／PCに適した余白・列幅・操作領域に調整。

### タスク

- 初期状態は **期限の早い順**。`期限順 / 担当者順` の切替ボタンがあります。担当者順は `🐧 → 🦉 → 🦜 → 未指定` を基本に、同じ担当なら期限順とします。複数担当の場合は担当者の並びで比較します。
- 完了したタスクは、どちらの並び替えでも**末尾にまとめて表示**し、行全体がグレーアウトします。
- 画面右上の**目のアイコン**で完了タスクの表示・非表示を切り替えます。
- ステータス配色：**進行中＝青、レビュー依頼＝赤、保留＝黄色、完了＝灰色**。
- iPhoneなどの小さい画面でも、PCと同じ6列（分類／タスク名／ステータス／期限／担当／備考）を**横長の1行形式**で表示します。画面上で左右にスクロールして閲覧します。
- ＋ボタンでタスク追加。フォームを開いても入力欄に自動フォーカスしないため、すぐにキーボードが起動しません。

### 曲リスト

- 右端のボタンを「**詳細**」に変更。
- **Capo順（デフォルト）だけ**レギュラー／DADGADでグループ表示。名前順、演奏時間順はチューニングに関係なく全8曲を1つの一覧に並べます。後者2モードでは行内にチューニングを表示します。
- 曲リスト自体は編集不可のままです。

### 曲詳細

- 「構成」列の幅を調整し、最も長い見出し（例：`【間奏3　Gt.ソロ】`）も列の幅からはみ出さないようにしています。
- 「＋」で新しい列を追加すると、**歌詞・備考のすぐ右（3列目）に挿入**し、それまでの追記欄は右にずれます。
- ヒートストアの「🟢上手です」などの既存コメントを、歌詞欄から**3列目の追記メモ**へ移動しています。改行を維持しています。
- 「追記メモ 1」などの**列名の右上の鉛筆ボタン**で名称を自由に変更できます（30文字まで）。
- 各追記セル右上の鉛筆ボタンから内容を編集でき、端末内へ自動保存します。追記列は最大6列（全体8列）です。
- スマホでは横スクロール。左端の「構成」列が固定されます。

### 練習タイテ

- 練習時間を**開始時刻と終了時刻の2つの時刻選択**に変更。画面上は `09:30〜12:00` のような**24時間形式**で表示します。時間はiPhoneの時刻選択UIから変更できます。
- 開始時刻から各項目の継続時間を合計し、**`09:30〜09:50`** のようにそれぞれの予定時間帯を自動表示します。項目の追加・削除・移動・分数変更に連動します。終了時刻が開始時刻より早い場合は翌日とみなして計算します。
- 項目行をコンパクトにして、継続時間の選択肢と備考欄を小さくしました。各項目の継続時間はこれまでどおり5分刻みです。
- 上部ヘッダー全体を**3等分**し、各スロットの名前を表示します。名前の横の鉛筆アイコンで編集できます。3スロットの内容はそれぞれ自動保存されます。
- スマホでも**左＝作成中、右＝追加メニュー**の左右2列です。

### セトリ作成

- 練習タイテと同じ**3分割ヘッダー・名前編集**へ変更しました。
- レギュラーは**薄い青**、DADGADは**やや濃い青**、その他は**グレー**で表示します。
- スマホでも**左＝作成中、右＝選曲メニュー**の左右2列です。

## 更新する方法

1. 事前に既存のWebアプリの「曲リスト」右上の保管箱から**JSONバックアップ**を保存することを推奨します。
2. `Koryosan_PWA_v4_GitHubPages.zip` を解凍します。
3. GitHubの既存リポジトリ `koryosan` を開き、`Code → Add file → Upload files` を選択します。
4. 解凍した **`Koryosan_PWA_v4` フォルダの中身**（`index.html`、`.js`、`.css`、`icons/` 等）を、リポジトリのルートへアップロードして `Commit changes`。ZIPファイルそのもの、または外側のフォルダをアップロードしないでください。
5. `Settings → Pages` が `Deploy from a branch / main / (root)` になっていることを確認し、`Actions` にてデプロイ成功を確認。
6. 公開URLをSafariなどで再読み込み。ホーム画面から開くPWAでは、一度アプリを終了して開き直してください。

公開URL： https://kaiutsunomiya-jpg.github.io/koryosan/

`sw.js` のキャッシュ名を `koryosan-static-v4` に更新しているため、オンラインで新版を読み込んだあとはオフラインでも利用できます。

## 既存データの引き継ぎ

- ローカル保存キーを**`koryosan.app.v1` のまま**使用。v3のタスク・全6スロット・曲別追記メモ・メトロノーム設定を引き継ぐことを想定しています。
- 旧版の練習時間（例：90分）は、最初に新画面で表示するとき **18:00〜19:30** へ自動変換します。既定の120分スロットは **18:00〜20:00** です。開始／終了時刻は後から変更できます。
- 旧版ですでに3列目へ追記していた曲は、その内容とヒートストアの固定コメントを両方残すように移行します。
- **メンバー間のリアルタイム同期は未実装です。** 編集データは各端末内へ保存されます。端末変更・削除前は必ずバックアップしてください。
