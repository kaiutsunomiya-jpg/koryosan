# 校了さん v14｜R2音源選択・Firebase小節マップ

## 導入の順序

1. **Firebaseをバックアップ**：Realtime Database のルート `/` から現在のJSONをエクスポート。
2. **小節データを登録**：`/bands/koryosan/songBarMaps` に、配布の `Koryosan_v14_Firebase_songBarMaps_青い窓.json` を「JSONをインポート」で登録。登録内容は `ky-05` の227小節・拍子・構成マーカー。既存曲や曲メモは含まれません。
   - `songBarMaps` がまだ存在しなければ、`/bands/koryosan` の「子を追加」からキー `songBarMaps` を作成（作成時の値は仮の `0` でよい）。その子ノードを選択してJSONをインポートすると、仮の値が置き換わります。
   - **誤って `/bands/koryosan` や `/` にインポートしないこと。** そこにインポートすると既存のバンド情報を置き換えてしまいます。
3. **GitHub Pages更新**：ZIPを解凍し、`koryosan-main/` の中のPWAファイルを既存GitHubリポジトリ `koryosan` のルートへ上書きアップロード。
4. 旧版の静的ファイル `aoi_mado_bar_map.json` は不要です。GitHubに残っていれば、任意で削除できます（新版は参照しません）。
5. ブラウザで左下 `v14` を確認 → `曲リスト → 青い窓 → 詳細` → 追記列の2行目でR2ファイル選択 → 1行目の **▶** で小節追従ポップアップを開く。

## 新しいFirebaseの保存形式

- `bands/koryosan/songBarMaps/ky-05`：MIDI由来の小節開始時刻・拍子・構成マーカー。アプリで閲覧のみ。新曲は `ky-XX` の子ノードを追加して拡張。
- `bands/koryosan/songNotes/ky-05/columns/<列ID>/audioKey`：その追記列の2行目で選択したR2オブジェクトキー。選択時に自動作成・差分保存。
- `.../filename`：選択時にファイル名も自動保存。従来の `title`、`description`（旧Google Drive URL）、`overall`、構成ごとのメモは保持。

**既存のデータ全体を上書きするJSONの再インポートは不要です。** `songBarMaps` だけ追加してください。

## Firebaseルール

既存の `/bands/koryosan` の `.read` が認証済みメンバーに許可されていれば、小節マップの読み取り権限も引き継がれます。新しいアプリ側から小節マップを書き込む処理はないため、通常はルール追加不要です。必要であれば `"songBarMaps": {".write": false}` を `bands/koryosan` の同階層へ追加し、管理画面からのみ更新してください。ルール全体を置き換えないでください。

## Cloudflareについて

**v13で動いているWorkerを変更する必要はありません。** R2の `/api/audio/list` と `/api/audio/file` をそのまま利用します。R2バケットは非公開のまま維持します。メンバー認証も従来のFirebase IDトークンを使います。

## UI・利用上の注意

- 追記メモのない曲詳細は、構成と歌詞の2カラムを同じ幅で揃えて表示します。
- 追記メモ2行目には、R2から返されたMP3/WAVファイルを一覧表示。右上の `↻` で再取得できます。
- 選択したファイルのキーはFirebaseに保存されます。選択済みファイルがR2から削除された場合は再生できません。
- 列の▶は、その列のメモを含む小節追従プレーヤーを表示します。小節データ未登録の曲では、通常の時間シーク再生に切り替わります。
- 72時間の端末キャッシュはv13から引き継ぎます（初回取得後最大80MB/ファイル、ブラウザによっては早期削除）。
- 青い窓のMIDIは計227小節、200 BPM、10構成マーカー（拍子変更あり）。音源の曲頭の無音・テンポ差はプレーヤーの「開始ずれ」で調整します。

## 検証

Chromiumによる画面幅1280/390/320pxの表示・操作テスト、0列の構成/歌詞位置一致、R2ファイルプルダウン、選択時のFirebase差分、▶でモーダルが開き227小節を表示する処理を検証。実際のCloudflare R2・Firebaseサーバーへの接続は未実施のため、公開後に実機で確認してください。
