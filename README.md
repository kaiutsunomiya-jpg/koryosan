# 校了さん PWA v7 — Firebase本番版

今回のZIPは、統合版v6をベースに2026-11-20時点の指定4点を更新したものです。**既存のログイン・リアルタイム同期・曲リスト・タスク・練習タイテ・セトリ・スケジュール・空き日程・会議・メトロノームを保持**します。

## v7の修正

1. モバイルのダブルタップ・ピンチによる意図しない拡大を抑制（viewportとタッチ操作制御）。ブラウザのアクセシビリティ設定によっては完全な拡大禁止は保証されません。
2. 空欄に表示していた「未設定」「自由記述」「説明・リンクなど」等のプレースホルダー・余計な案内を除去。
3. 曲詳細の👀ボタンとレビュー画面を削除。過去のレビュー関連JSONは互換性維持のため、表示しない状態で残します。レビューの新規入力はできません。
4. 追記メモが0列でも、**構成・歌詞の2カラム**を維持。メモ列は＋で追加でき、最後のメモ列を削除しても2カラムを維持。

## GitHub Pagesへの更新

1. Firebase Realtime Databaseから**現在のルートJSONをバックアップ**します。
2. 本ZIPを解凍し、ZIP内のアプリファイルと`icons`フォルダをGitHubの本番リポジトリ（`koryosan`など）の**ルート**に上書きアップロードします。
3. GitHub → Actionsからデプロイ成功を確認します。キャッシュの更新バージョンは`koryosan-static-v7`です。必要に応じてアプリを閉じ、オンラインで再起動してください。

## Firebase上書き用JSON（ZIPには入れていません）

**別途お渡しする `Koryosan_Firebase_v7_上書き用.json` を、Realtime Databaseの `/bands/koryosan` ノードにインポートしてください。**

1. Firebase Console → Realtime Database → 「データ」を開く。
2. 右端のメニューから「JSONをエクスポート」を選び、**現在のデータ全体をバックアップ**する。
3. バンドメンバー全員にアプリ操作を一時停止してもらう。
4. ツリーを展開して、必ず **`bands` → `koryosan`** まで移動し、`koryosan` ノードのメニューから「JSONをインポート」を実行する。
5. 別途の `Koryosan_Firebase_v7_上書き用.json` を選択する。
6. 再読み込みして、曲・会議・タスク・空き日程・スロット名を確認する。

**注意：JSONのインポート先はデータベースのルート`/`ではありません。** ルートでインポートすると、`members`（ログインを許可するUIDリスト）等が消えてログインできなくなる可能性があります。JSONは`/bands/koryosan` の子要素の形です。

**注意： `/bands/koryosan` にインポートすると、そのノードの現在の内容は指定データに上書きされます。** これまでのタスク・メモ・会議・空き日程入力・スロット内の曲や練習タイテの内容などは消えます。歌詞についても、今回の指定内容になります。必要なら先に手元に書き出してください。`/members`とFirebase Authenticationのユーザー・パスワードはこのJSONには含まれません。

## Firebaseルール

v6で `schedules`、`availability`、`meetings` に対する書き込みルールを追加済みであれば、新しいルール変更は不要です。`/bands/koryosan` の `.read` およびそれぞれの `.write` は、従来どおり `members` に登録されたUIDだけを許可する設定を維持してください。

歌詞と曲データは公開GitHubのアプリZIPに含まず、認証後にFirebaseから読み込みます。**上書き用JSONには歌詞やバンドの内部会議情報があるため、公開GitHubリポジトリには絶対にアップロードしないでください。**
