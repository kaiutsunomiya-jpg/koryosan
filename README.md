# 校了さん — バンド用PWA v3（GitHub Pages対応）

「さいわいさん」の4画面構成をベースに、**別バンド「校了」専用**のWebアプリとして作り替えたバージョンです。

- アプリ名：**校了さん**
- テーマカラー：ブルー系（ネイビー／スモーキーブルー）
- アプリアイコン：ユーザー添付の3人のカメラ写真をそのまま採用（1024 / 512 / 192 / 180pxのPNG）
- 画面：**タスク／曲リスト／練習タイテ／セトリ作成／メトロノーム**
- iPhone／PC対応、オフライン対応（初回の通信・キャッシュ作成が必要）
- Apple Developer Program／App Store不要。GitHub Pagesで無料公開可能

- 画面起動時に**レギュラー／DADGADで最初から分けて**表示します。

## 曲の詳細：左2列固定・3列目以降をセル単位で編集【v3追加】

「曲リスト」→「ヒートストア」右端の楽譜アイコンで開けます。

- **第1列：構成（編集不可）**。`【イントロ】`、`【1A】`、`【1サビ】` など、提示された15区間の名称を表示します。
- **第2列：歌詞・備考（編集不可）**。指定された歌詞と🟢コメントを表示します。入力された改行のみを維持し、画面幅に応じて勝手に改行しません。
- **第3列：追記メモ1（編集可能）**。**各セルの右上の「編集」ボタン**から編集画面を開き、その区間のメモを自由入力できます。内容を空欄で保存すると削除（空欄に戻す）できます。
- **第4列以降**：詳細画面上の「＋ 列を追加」で追加できます。追加した列の各セルにも編集ボタンがあります。追記欄は最大6列（表全体では最大8列）です。
- スマートフォンでは、**横にスクロールして第3列以降を表示**します。第1列「構成」は固定表示し、どの行を編集しているか分かるようにしました。最初に表示される2列の大きさは画面幅に合わせています。
- **編集内容は端末内に自動保存**されます。更新前・機種変更前にJSONバックアップを保存してください。バックアップには曲ごとの追記欄も含まれます。
- 追記欄は**曲ごと・区間ごと・列ごとに独立**しています。今後ほかの曲に構成・歌詞を追加した際にも拡張できるようにしています。

## 2. 練習タイテ：3スロット

画面右上の**1／2／3**からスロットを切り替えます。左上に「新規」は置かず、右上にも「保存」「読込」ボタンはありません。

- **各スロットは独立**しています。スロット名、練習時間、追加した項目、時間、備考、並び順をそれぞれ保存します。
- スロット名は画面上部の**入力欄**から自由に変更できます。変更内容は都度**自動保存**されます。
- 練習時間は初期120分（各スロット個別）。合計時間・残り時間が自動計算されます。
- 追加メニューは「準備（20分）」「通し（30分）」「セクション（25分）」「バッファ（10分）」「休憩（10分）」「片付け（10分）」。同じメニューを何度でも追加できます。
- 左側（スマホでは上側）に追加した項目ごとに、**5〜240分の5分刻み**で時間を調整でき、備考には曲名などを書けます。
- ⠿ をドラッグして順序変更、×で削除できます。コピーもできます。

## 3. セトリ作成：3スロット

- 画面右上の**1／2／3**で独立したセトリを切り替えます。
- 各スロットの**名前・持ち時間（初期30分）・選曲・曲順**を自動保存します。保存や新規ボタンは不要です。
- 追加候補は **レギュラー → DADGAD → その他** の順にグループ表示します。
- 各チューニング内の曲は、Capoなし（—）→ Capo1 → Capo2… の昇順です（同じCapoでは曲名順）。
- 元のアプリにあった「tuning」「MC」「ミニMC」「イントロ追加」は、持ち曲に数えず「その他」に残しています。持ち時間の計算には含みます。
- 曲の重複追加、ドラッグで順序変更、×で削除、残り時間の表示、テキストコピーに対応します。

## 4. メトロノーム

- 以前の「TEMPO SWITCH」型のメトロノームを移植。A/B/CのBPM（初期100/120/110）とシーケンスを編集できます。
- シーケンス初期値は B→A→B→A→B→A→B→A→B→C。ワンタップで次のテンポに進み、最後の次は先頭に戻ります。
- 音色の選択・変更はありません。すべて同じ、**減衰約35msの硬い短音**を鳴らします（小節頭も強調しません）。
- 開始・停止、音ON/OFF、編集取り消し・全消去、テンポの端末保存に対応。ほかの画面に移動すると再生は停止します。

## GitHub Pagesで公開する方法

**「さいわいさん」のリポジトリに上書きせず、別の公開リポジトリを作ってください。** 例えば `koryosan` を使えます。

1. GitHubで新しいリポジトリを作成。名前は **`koryosan`**、公開範囲は **Public**。
2. ZIPを解凍して `Koryosan_PWA` を開き、中身をアップロードします。**ZIPそのものや外側のフォルダをアップロードしないでください。**
3. GitHubのリポジトリで **Code → Add file → Upload files**。空のリポジトリなら **uploading an existing file** をクリックします。
4. `index.html` がリポジトリのルートにあり、`icons` フォルダもアップロードされていることを確認して `Commit changes`。
5. **Settings → Pages** で **Source: Deploy from a branch / Branch: main / Folder: /(root)** を選択して保存。
6. `Actions` でPagesのデプロイ成功を確認し、iPhoneのSafariでサイトへアクセス。
7. Safariの共有メニューから **「ホーム画面に追加」** を選択します。

アカウント名・リポジトリ名が上記どおりの場合、公開URLの形式は：

`https://kaiutsunomiya-jpg.github.io/koryosan/`

## 保存・バックアップについて

- 画面上の3スロットは各端末の**ローカルストレージ**に自動保存します。
- **校了さんは「さいわいさん」と異なるアプリ**です。ローカル保存キーも `koryosan.app.v1` と `koryosan.metro.v1` に分けています。
- 曲リスト画面右上の**保管箱アイコン**から、タスク・曲詳細の追記メモ・全6スロット＋メトロノーム設定のJSONバックアップを書き出し・読み込みできます。
- 端末変更、SafariのWebサイトデータ消去、ホーム画面アプリの削除などではデータが失われる場合があります。定期的にJSONバックアップを保存してください。
- このバージョンにはアカウントログイン・3人でのリアルタイム共有は実装していません。GitHub Pagesは静的配信なので、メンバー間の自動同期にはFirebase等の別サービスが必要です。
- GitHubの公開リポジトリ内の初期曲リストとアイコン画像は**第三者からも閲覧可能**です。非公開の楽譜や機密情報はリポジトリにアップロードしないでください。

## v2からv3へ更新する場合

GitHubの公開URL・リポジトリを**変える必要はありません**。`Koryosan_PWA_v3_GitHubPages.zip` を解凍し、`index.html`、`app.js`、`styles.css`、`sw.js`、`details.js` などフォルダ内のファイルと `icons/` を、既存の `koryosan` リポジトリ直下へ上書きアップロードしてください（**ZIP自体はアップロードしない**）。Pagesのデプロイ後、オンラインで再起動して新版を読み込みます。

Service Workerのキャッシュ名を `koryosan-static-v3` に変更済みです。以前の `koryosan.app.v1` 保存データはそのまま読み込み、曲詳細の追記メモのみ追加のフィールドに保存します。**GitHub Pages上のファイルを差し替えても、ローカル保存データは通常削除されませんが、更新前のバックアップを強く推奨します**。

この版は端末ごとの保存方式です。追記メモもバンドメンバー間で自動同期されません。
